# 05. B2B 转化率优化 (CRO) 与工业级组件规范 (B2B CRO Components)

针对海外采购决策链冗长、买家专业挑剔的特点，传统的营销型“瀑布流长图”已彻底失效。本规范定义了出版级 B2B 工业界面的高转化组件系统。

---

## 一、工业 Bento Grid 栅格体系 (Data-Priority Layout)

Bento 栅格的核心原则不是“为了拼图而拼图”，而是**依据采购决策数据优先级（Data Priority）定格**：

```
┌───────────────────────────────────────┬───────────────────────────────┐
│               Card 1                  │            Card 2             │
│        智造规模与年产能硬指标           │      7–10 天急速出样打样通道   │
│   (例如: 2条全自动成型线 / 500万双年产) │      (3D CAD/CAM 极速响应)    │
├───────────────────┬───────────────────┼───────────────────────────────┤
│      Card 3       │      Card 4       │            Card 5             │
│   8道质检与AQL     │    四大权威国际认证  │      公英双制式参数下载中心   │
│   0.65/1.5标准    │   (CE, FDA, ISO)  │   (TDS / BIM / 3D STEP / CAD) │
└───────────────────┴───────────────────┴───────────────────────────────┘
```

### Bento 设计准则：
- **数字大字原则**：核心产能、合格率、交期天数采用 `var(--font-mono)` 放大至 36–48px，右侧或下方紧随公信力证据；
- **微边框重于模糊投影**：采用 1px 精准浅灰描边 `1px solid var(--brand-border)`，赋予界面精密、严谨的德国工业仪器感；
- **微交互反馈**：卡片悬停时 `transform: translateY(-2px)`，配合浅淡阴影平滑过渡，杜绝剧烈跳动。

## 二、交互式集装箱海运与到岸成本测算器 (Sourcing Estimator)

海外批发商与工程总包商最核心的痛点是**“海运费与单件装柜成本”**。独立站直接提供实时前端测算工具，停留时长可提升 300%：

### 1. 测算逻辑：
- 输入：选定 SKU + 计划订购件数 + 目标集装箱规格（`20GP: 28 CBM / 18,000 kg` 或 `40HQ: 68 CBM / 26,000 kg`）；
- 输出：
  - 占用总体积（Total CBM）与总毛重（Gross Weight kg / lbs）；
  - 集装箱装载容积利用率（Volumetric Fill Rate %）；
  - 推荐最优托盘排布方式（Pallet Packing Configuration）；
  - 测算结果一键生成 PDF 报价单或作为 WebMCP 参数自动提交。

## 三、移动端人体工学 3 键拇指船坞 (Bottom Sticky Thumb-Dock)

### 痛点破局：
在移动端（屏幕宽度 $\le 768px$），悬浮的在线客服气泡往往会遮挡关键产品参数表与表单按钮，导致买家误触跳出率高达 45%。

### 规范解决方案：
全站移动端统一采用**底部固定 3 键操作船坞（Fixed 3-Button Dock）**，居于单手拇指黄金操作区：

```
┌────────────────────────────────────────────────────────┐
│  [💬 WhatsApp Direct]  [📦 Order Sample]  [📥 Spec PDF] │
└────────────────────────────────────────────────────────┘
```
1. **WhatsApp Direct**：点击一键直达官方业务 WhatsApp 聊天，预置问候语与产品型号；
2. **Order Sample**：滑出底部抽屉层（Bottom Sheet），展开轻量化 WebMCP 索样表单；
3. **Spec PDF**：即刻在新标签页打开该品类官方 TDS 技术数据手册。

## 四、公英双制式全局切换器 (Metric / Imperial Switcher)

北美买家习惯使用 `inch`、`lbs`、`sq ft`、`psi`，而欧洲、中东与亚太买家使用 `mm`、`kg`、`㎡`、`MPa`。

在参数表格右上角注入轻量切换按钮：
- 切换时通过 CSS 类选择器 `.unit-metric` 与 `.unit-imperial` 实现零重绘、零闪烁秒切；
- 避免传统网站因单位不同而造成的沟通误解与退货索赔。

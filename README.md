## 🏛️ 三轨路由与 8+1 构建阶段 SOP

### 1. 三轨智能路由 (Triple-Track Workflow)
- **Mode A（默认：买家洞察原创增长与 8+1 阶段 SOP）**：前置跨境产品情报穿透 $\rightarrow$ `docs/seo/` 唯一事实源中枢、6 大采购意图词树与买家 4 角色 JTBD $\rightarrow$ 三互补标杆机制蒸馏与文化双轨重命名 $\rightarrow$ Anthropic 反 AI-Slop 两轮设计与 OKLCH 字阶令牌 $\rightarrow$ 首屏零摩擦工作台、双模海运装柜算力与三级风险逆转询盘漏斗 $\rightarrow$ 同源事实编译、SKU 目录审计与 Clean URLs $\rightarrow$ 134–167 词 GEO 直答块（`citability-score >= 85`）与五层端点 $\rightarrow$ Hub-and-Spoke 主题内链缝合、30 天排期行业智库长文引擎与站外品牌提及分发包 $\rightarrow$ Vercel 12 维体检、Cloudflare 默认边缘防护与 7 态外链台账。
- **Mode B（1:1 严格证据复刻与文化重塑分支）**：当明确要求“1:1 复刻/克隆某站”时，启动 `site_forensics.py` 探针取证、CSS Token 提取、文化双轨重命名脱敏、像素级契约还原、图实一致性核查（$\Delta E < 5$）及零视觉变动注入 GEO 五层端点。
- **Mode C（通用 Skill 七步机制蒸馏工作流）**：当输入包含“优化这个 Skill：〈路径/仓库〉”时，执行两层能力缺口诊断（通用 vs 领域，不向非网站类 Skill 强加 SEO/关税规则）、GitHub/Hugging Face 资源甄别、六步机制蒸馏链、代码改造、三态经验验证与 `SKILL_OPTIMIZATION.md` 报告交付。

### 2. 全行业 8+1 构建阶段全景表

| 阶段 | 阶段名称 | 核心交付与执行机制 |
|---|---|---|
| **阶段零** | **跨境爆品情报穿透 & 全球三大巨头标杆排查** | 穿透 TikTok/Amazon/Google Trends/海关提单 5 大信号源测算 DVI 爆款；锁定细分赛道**三大巨头**（① 技术规范与 GEO 权威、② 高端视觉溢价天花板、③ 场景长尾词之王） |
| **阶段一** | **`docs/seo/` 唯一事实源、6 大意图词树与买家 4 角色 JTBD** | `orchestrator.py` 自动初始化 `docs/seo/` 12 文件工作区与 `.claude/CLAUDE.md`；评估 `M0/M1/M2` 成熟度；生成 6 大采购意图分支词树（锁定 H1/H2 契约与 SERP 弱点核验）；拆解采购委员会 4 角色弹药与官方关税 |
| **阶段二** | **机制蒸馏、文化双轨重命名与图实一致铁律** | 对照学习与反事实去冗余；建立 `[文化主名] [工艺/功能] [品类词]` 双轨命名剥离 Trademark；微距实拍与场景图色差 $\Delta E < 5$ |
| **阶段三** | **Anthropic 反 AI-Slop 两轮设计、OKLCH 令牌 & 工程标准锚定** | 四大工业视觉原型自动生成 `src/styles/design-tokens.css`（Major Third `clamp()` 字阶、OKLCH 中性色、禁用霓虹渐变与 `shadow-xl`）；全站绑定 ASTM/CE/FDA/ISO/DIN/JIS/ГОСТ 实测指标 |
| **阶段四** | **首屏零摩擦工作台、双模装柜算力 & 三级风险逆转询盘漏斗** | 首屏嵌入材质/规格切换或装柜计算器；`design_math.py` 提供**外箱体积模式 (`container`)** 与**重货限重模式 (`stone-container`，20GP 限重 26.5 吨)**；三级商业询盘卡（NDA 保密 / 样品费抵扣大货 / AQL 验货）取代 SaaS 付费墙 |
| **阶段五** | **同源事实编译、批量 SKU 审计 (`catalog-audit`)、Clean URLs 与 Anti-FOUC** | 核准事实卡同源生成 HTML、`B2bJsonLd.tsx`、Sitemap；`seo_geo_matrix.py catalog-audit` 审计批量 SKU；全面剥离 `.html` 后缀；CSS 内容哈希 `?v={hash}` 与隐藏抽屉内联隔离 |
| **阶段六** | **134–167 词 GEO 直答块 (`citability-score`) & 五层 AI 端点** | 编写 134–167 词自包含工程直答段落与 `tabular-nums` 语义化 `<table>`，通过 `citability-score` 0–100 分双轨审计（目标 $\ge 85$）；`llms: true` 发布构建自动产出 `/llms.txt`、`/llms-full.txt` 与 `/ai/*.json` |
| **阶段七** | **Hub-and-Spoke 内链缝合、30 天排期智库 & 站外品牌提及分发** | `topic-cluster` 规划 Hub/Spoke 技术锚文本内链桥；`scheduled_content_engine.py` 管理 30 天排期长文队列（每篇 ≥3,000 字、≥2 图）；`syndication-pack` 输出 LinkedIn/Medium/YouTube 验厂字幕品牌提及包 |
| **阶段八** | **Vercel 12 维体检、10 项双轨审计、边缘防护与 7 态外链台账** | `layout_typography_auditor.py --strict` + `validate_site.py`；Cloudflare Workers 默认防护包；`init-ledger` / `validate-ledger` 管理 7 态证据化外链台账；[6 大防错军规](references/failure-cases-and-guardrails.md) |

## 快速开始与核心工具链

将本仓库安装到 Agent 的 skills 目录（如 `~/.gemini/config/skills/b2b-global-brand-site-master/` 或 `~/.codex/skills/b2b-global-brand-site-master/`），以 [SKILL.md](SKILL.md) 为入口。

```bash
# 1. 查看全部 22 个行业蓝图并一键初始化项目 + 21模块事实底座 + docs/seo/ 唯一事实源中枢
python3 scripts/sitekit.py industries
python3 scripts/orchestrator.py --name "Example Company" \
  --intro "We quarry and process architectural limestone pavers." \
  --industry limestone --seed "tumbled limestone pavers" \
  --out /tmp/example-company-project

# 2. 编译草稿与发布候选 (release 模式下若 llms=true 自动生成 /llms-full.txt 与 /ai/*.json)
python3 scripts/orchestrator.py --project /tmp/example-company-project
python3 scripts/orchestrator.py --project /tmp/example-company-project --release

# 3. B2B SEO/GEO 词树、Hub-and-Spoke 聚类、0-100 分 GEO 可引用性评分、SKU 审计、站外品牌提及包与 7 态外链台账
python3 scripts/seo_geo_matrix.py keyword-tree --seed "tumbled limestone pavers" --industry limestone --markets "US,UK,AU"
python3 scripts/seo_geo_matrix.py topic-cluster --seed "tumbled limestone pavers" --industry limestone --market "US"
python3 scripts/seo_geo_matrix.py citability-score --file /path/site-output/products/index.html
python3 scripts/seo_geo_matrix.py catalog-audit --file /path/company-project/content/skus.json --industry limestone
python3 scripts/seo_geo_matrix.py syndication-pack --company "Example Company" --seed "tumbled limestone pavers" --industry limestone
python3 scripts/seo_geo_matrix.py geo-prompts --company "Example Company" --seed "tumbled limestone pavers" --industry limestone
python3 scripts/seo_geo_matrix.py init-ledger --out /tmp/example-company-project/private/backlink-ledger.json
python3 scripts/seo_geo_matrix.py validate-ledger --file /tmp/example-company-project/private/backlink-ledger.json

# 4. 运行站点完整性审计 + Vercel 12 维 UI/UX 与 Clean URLs 严格体检
python3 scripts/validate_site.py /path/site-output --release --domain https://example.com
python3 scripts/layout_typography_auditor.py --strict /path/site-output

# 5. 设计数学、安全 URL 拼接与双模集装箱装柜算力
python3 scripts/design_math.py contrast '#334155' '#ffffff'
python3 scripts/design_math.py fluid 36 64 360 1440
python3 scripts/design_math.py safe-url https://example.com stone-flooring/limestone
python3 scripts/design_math.py container --length 540 --width 380 --height 420 --weight 14.5 --pcs 24
python3 scripts/design_math.py stone-container --area 480 --thickness 20 --density 2620

# 6. 30 天排期行业智库长文引擎 (≥3,000字 & ≥2图/篇) 与单页取证探针
python3 scripts/scheduled_content_engine.py --self-test
python3 scripts/scheduled_content_engine.py --audit-queue
python3 scripts/site_forensics.py https://example.com /tmp/evidence-capture
```
